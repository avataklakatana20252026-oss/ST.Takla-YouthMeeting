تطبيق اجتماع الشباب بكنيسة الأنبا تكلا هيمانوت الحبشي بأشمون - الصلاة السهمية

1) أنشئ مستودع GitHub جديد باسم jesus-prayer-tekla واختر Public.
2) بعد إنشاء المستودع اختر Add file ثم Upload files.
3) فك ضغط ZIP على الكمبيوتر أولاً، واسحب جميع محتويات المجلد الناتج (بما فيها مجلد .github) إلى صفحة الرفع. لا ترفع ملف ZIP نفسه وحده.
4) اضغط Commit changes.
5) افتح Actions واختر Build Android APK ثم Run workflow.
6) بعد نجاح التشغيل افتح تشغيل البناء، ثم من Artifacts نزّل YouthMeetingTekla-APK.
7) فك ضغط الأرشيف الذي نزّلته من GitHub وستجد app-debug.apk. انقله إلى موبايل أندرويد وثبته (قد تحتاج السماح بالتثبيت من هذا المصدر).

ملاحظات:
- المقطوعة الموسيقية تجريبية أصلية مولّدة رقمياً بصوت يشبه الآلات الوترية، وليست تسجيل عود حقيقي. يمكن لاحقاً استبدالها بتسجيل عود مرخّص.
- الموسيقى مغلقة افتراضياً، ويمكن تشغيلها أو إيقافها وتعديل الصوت من داخل التطبيق.
- لا يحتاج التطبيق إلى اتصال بالإنترنت.
- هذا إصدار تجريبي Debug APK للاختبار الشخصي وليس إصدار متجر موقَّع للتوزيع.
