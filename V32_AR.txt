نوتتي الروحية V32 — Android + iPhone PWA
1. قبل رفع الملفات: Settings > Pages > Source > GitHub Actions (بدلا من Deploy from a branch).
2. ارفع محتويات المشروع كاملة إلى main، بما فيها .github وweb وtools وdocs. لا ترفع مفتاح التوقيع أو كلمات المرور.
3. Actions > Build Android APK > Run workflow > main. فعّل publish وdeploy_web ثم Run workflow. يمكن تفعيل deploy_web وحده لإعادة نشر الموقع إذا سبق نشر APK v32.
4. بعد نجاح build وdeploy-web، افتح الرابط الحالي للموقع. زر Android يحمل notety.apk من أحدث إصدار؛ زر iPhone يفتح /app/.
5. على iPhone: Safari > مشاركة > إضافة إلى الشاشة الرئيسية. افتح من الأيقونة مع الإنترنت حتى يكتمل التخزين المؤقت. اختبر القراءة في وضع الطيران بعد ذلك.
6. التنبيهات المجدولة أثناء إغلاق تطبيق الويب غير متاحة. السجلات محلية؛ تصدير واستيراد JSON في إعدادات نسخة الويب، دون مزامنة بين الأجهزة. احتفظ بنسخة احتياطية خاصة. لا تحذف نسخة Android القديمة.
7. لا توجد قراءات سنوية وهمية: يستورد البناء المراجع الأصلية ويتوقف إن لم يكتمل التحقق. اختبارات التغليف المحلية استخدمت بيانات اختبار مؤقتة فقط، ولم تُضمّن في المشروع. لم يُختبر APK أو Safari فعليا هنا.
